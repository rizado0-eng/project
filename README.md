# Сайт кредитного брокера «Согласовано»

Многостраничный сайт кредитного брокера, собранный из согласованных материалов клиента: реального логотипа, фирменных цвета/шрифта, готовых иллюстраций, логотипов банков-партнёров и текстов по всем блокам ТЗ. Статика, без сборки — открывается в браузере или деплоится на любой хостинг.

## Структура

```
index.html            — главная страница
quiz.html              — квиз «Кредитный ДНК» (ветвление физлица / ИП / ООО)
privacy.html           — политика обработки персональных данных
products/
  collateral.html      — кредит под залог недвижимости
  cash.html            — кредит наличными
  auto.html            — автокредит
  business.html        — кредиты бизнесу
  refinance.html        — рефинансирование залога
  mortgage.html         — ипотека
assets/
  css/styles.css
  js/main.js            — шапка, меню, FAQ, формы, баннер о мошенниках
  js/quiz.js             — логика ветвления квиза
  fonts/malgun-subset.woff2   — фирменный шрифт (обрезан до кириллицы/латиницы)
  img/logo.svg, logo-white.svg
  img/illustrations/*    — фирменные иллюстрации и иконки
  img/partners/banks/*    — логотипы банков-партнёров (20)
  img/partners/insurance/* — логотипы страховых партнёров (12)
  img/partners/developers/* — логотипы застройщиков-партнёров (10)
```

## Источник контента

Все тексты, логотип, палитра (#3b44e3), шрифт (Malgun Gothic) и иллюстрации взяты из присланных согласованных материалов (папка «СОГЛАСОВАНО»: блоки #1–#11). Названия банков и партнёров — реальные логотипы из материалов клиента.

## Что нужно доделать перед публикацией

1. **Телефон компании.** Сейчас везде стоит плейсхолдер `8 800 000-00-00` — в исходных материалах номер тоже был не указан (`[номер телефона]`). Замените на реальный номер во всех HTML-файлах.
2. **Подключить приём заявок.** Формы (`assets/js/main.js`, `form[data-lead-form]`) сейчас только логируют данные в консоль. Нужно отправлять их в CRM/на почту через реальный API-эндпоинт.
3. **Юридические реквизиты.** `privacy.html` — заготовка, нужно согласовать с юристом (ОГРН/ИНН, юридический адрес) под 152-ФЗ.
4. **Адрес офиса.** В футере указан только регион (Москва и МО) — добавьте точный адрес, если есть офис.
5. **Квиз «Кредитный ДНК».** Сейчас результат теста — экран с призывом оставить заявку; ответы логируются в консоль (`assets/js/quiz.js`). При необходимости подключите передачу ответов в CRM вместе с заявкой.
6. **Проверить лицензии на логотипы партнёров.** Убедитесь, что использование логотипов банков/страховых/застройщиков в разделе «Партнёры» согласовано с реальными партнёрскими договорами.

## Локальный просмотр

```
python3 -m http.server 8000
# затем открыть http://localhost:8000
```
