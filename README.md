# Сайт финансового брокера

Статический лендинг для брокерской/финансовой организации (кредиты, ипотека, автокредиты, бизнес-кредиты, рефинансирование, страхование). Один файл `index.html`, без сборки и зависимостей — открывается в браузере или деплоится на любой статический хостинг.

## Структура

```
index.html          — главная страница (все секции)
privacy.html         — заготовка политики обработки персональных данных
assets/css/styles.css
assets/js/main.js
```

## Что реализовано

- Адаптивная вёрстка (десктоп/планшет/мобильный), тёмная/светлая тема с переключателем (сохраняется в localStorage)
- Герой с анимированным фоном и блоком актуальных ставок
- Стрип доверия (лицензии/стандарты), анимированные счётчики статистики
- Сетка услуг (7 карточек)
- Рабочий кредитный калькулятор (аннуитетная формула, переключение типа кредита, слайдеры суммы/срока/ставки)
- Блок «Как это работает» (4 шага)
- Таблица сравнения с типовым брокером + блок про экологичность (безбумажный документооборот)
- Слайдер отзывов, аккордеон FAQ
- Многошаговая форма заявки с валидацией (сумма, имя, маска телефона, чекбокс согласия) и экраном успеха
- Плавающие кнопки (наверх, звонок), баннер cookie-согласия, прогресс-бар скролла
- SEO-метатеги, favicon, семантическая разметка, skip-link для доступности

## Что нужно доделать перед публикацией

1. **Название и логотип.** Сейчас везде стоит плейсхолдер «Ваш бренд» + абстрактный логотип-марк (`index.html`, `privacy.html`, `<title>`). Замените на реальное название и, при необходимости, доработайте SVG-логотип.
2. **Подключить приём заявок.** Форма (`assets/js/main.js`, обработчик `applyForm.addEventListener('submit', ...)`) сейчас только логирует данные в консоль. Нужно отправлять их в CRM/на почту/в Telegram через реальный API-эндпоинт.
3. **Реальные контакты и реквизиты.** Телефон, e-mail, адрес и юридические реквизиты в футере и `privacy.html` — заглушки, замените на настоящие.
4. **Юридические тексты.** `privacy.html` и согласие на обработку ПДн в форме — это шаблон-заготовка, требует согласования с юристом под 152-ФЗ и реальные реквизиты компании.
5. **Отзывы и цифры.** Тестовые отзывы и статистика (число клиентов, банков-партнёров и т.д.) — примерные, замените на реальные данные компании.
6. **Партнёрские банки.** В маркетинговых материалах не указаны названия конкретных банков намеренно — при наличии реальных партнёрств добавьте их логотипы/названия.
